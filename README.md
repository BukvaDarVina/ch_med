# Государственная больница «Хайлань»

Статичный лендинг для многопрофильной государственной клиники в Хэйхэ (КНР). Целевая аудитория — пациенты из России, интересующиеся лечением, стоматологией, косметологией и традиционной китайской медициной (ТКМ).

## Технологии

- **HTML5** — семантическая разметка
- **CSS3** — OKLCH цветовые токены, CSS Grid/Flexbox, CSS-переменные
- **Vanilla JS** — гамбургер-меню (без зависимостей)

## Структура

```
├── index.html          # Главная страница
├── assets/
│   ├── css/
│   │   └── style.css   # Основные стили
│   └── img/            # Изображения
├── robots.txt          # Инструкции для поисковых роботов
└── sitemap.xml         # Карта сайта для SEO
```

## Функционал

- Адаптивная вёрстка (desktop → mobile)
- Гамбургер-меню на мобильных устройствах
- Skip-to-content ссылка для доступности (a11y)
- ARIA-атрибуты и семантические теги
- SEO: Open Graph, Twitter Card, JSON-LD (Hospital schema)
- Lazy loading изображений
- Плавная прокрутка к якорям

## Установка

Проект статичный, не требует сборки или зависимостей.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/BukvaDarVina/ch_med.git
   ```

2. Откройте `index.html` в браузере или разместите на хостинге (GitHub Pages, Netlify и т.д.).

## Развёртывание

GitHub Pages:

1. Настройки репозитория → Pages → Source: `master` branch, `/ (root)`
2. Сайт будет доступен по адресу: `https://bukvadavina.github.io/ch_med/`
